# Dima Travel

## About the Project

Dima Travel is a travel agency website developed as a semester-end academic project at the end of my second year of engineering studies (Semester 4, 2026).

Built using HTML and CSS, the website presents a travel agency and showcases destinations through images, descriptions, and dedicated pages. The entire website is in French.

## Features

- **Homepage:** Introduction to the travel agency and its services.
- **About Us:** Presentation of the agency's concept and travel philosophy.
- **Featured Destinations:** Highlighted destinations with images and descriptions.
- **Destination Pages:** Dedicated pages providing more information about different destinations.
- **Navigation:** Links to national and international destinations.
- **Reservation Form:** A form featuring fields for first name, last name, email address, phone number, number of travelers, destination, and departure date.

## Technologies Used

- HTML5
- CSS3

## Language

French.

## Current Status

This project is currently a front-end website. The reservation form is a visual interface and does not yet process or submit reservations. No back-end functionality has been implemented.

## Future Improvements

Potential future improvements include implementing back-end functionality to process reservation requests and handle form submissions as I develop my web development skills.

## Project Context

This project was completed as part of a semester-end assignment during the second year of my engineering studies. It allowed me to apply HTML and CSS concepts to create a structured, styled, and navigable website.
